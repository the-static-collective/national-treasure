# 0. WHY THIS EXISTS

A physical crossover idea appeared almost accidentally:

> trading cards.

Not merch.
Not a collectible skin over an existing system.
Not a fixed combat game with Green words painted on top.

The proposed object is a **compressed aperture** into the same generative grammar the Collective has been discovering elsewhere.

The game begins tiny.

```text
LEMON
PEACH

TABLE
CHAIR

FLOOR
WALL
```

Then players notice relations.
They compose.
They compress.
They reexpress.
The results re-enter play.

The game should therefore be able to build more of itself from its own lawful play.

Working seal:

> **DON'T DESIGN THE WORLD. DESIGN THE MINIMUM GRAMMAR FROM WHICH PLAYERS CAN NOTICE A WORLD.**

This document preserves how that idea formed. It does **not** claim that the rules are finished, balanced, commercially viable, historically inevitable, or canonically constituted.

# 4. THE IRREDUCIBLE PARTICULAR

A major turn came from noticing why physical cards matter at all.

The conversation proposed that what people crave is not merely scarcity.

It is **particularity with a worldline**.

```text
TYPE != TOKEN
SAME PRINTED SURFACE != SAME FORMATION HISTORY
PRICE != VALUE != MEANING
```

Two cards may begin materially equivalent.

```text
c1 ~= c2
```

Then they travel through different relations:

```text
c1 -> play -> trade -> witness -> damage -> repair -> PRUNE -> c1'
c2 -> another road                                      -> c2'
```

The distinction is not manufactured rarity alone.

Working term:

> **EMERGENT IRREPRODUCIBILITY**

A common card may become singular because only that physical carrier took that road.

This produced a foundational pair:

```text
CARD FACE      = what this could be
CARD WORLDLINE = what this one became
```

And a deeper compression:

> **THE PARTICULAR CAN CARRY A RELATION THE AGGREGATE CANNOT SUBSTITUTE.**

This is a generated relational reading. Biblical examples discussed in conversation — the pearl of great price, the lost coin, the widow's two coins, the one sheep among the hundred — were treated as pressure examples for particularity and relational value, not as one unified biblical economic theory of collectibles.

# 5. GREECEIPTS

The card itself may contain places where history can be left.

Not decorative achievement boxes.
Not arbitrary XP counters.

**GREECEIPTS** are physical receipt surfaces.

Possible fields:

```text
ENCOUNTERED   [ ]
RELATED       [ ]
WITNESSED     [ ]
CROSSED       [ ]
BECAME        [ ]
PRUNED        [ ]
REEXPRESSED   [ ]

WITNESSED BY: __________________

DELTA:
________________________________
```

These fields are not all necessarily explained at first order.

A crucial mechanic emerged:

> **THE EMPTY BOX CAN BE A QUESTION.**

Possessing the card does not imply having unlocked every operation the card can support.

```text
POSSESSION != AUTHORITY
LICENSE != SUCCESS
```

A higher-order endorsement means only that the player or card has earned the right to attempt a class of relation.

It does not promise the crossing will hold.

The quest can therefore depend on **formation history**, not only on print rarity.

# 7. THE FOUR CARD CORNERS

A recursive HJJ pass found a compact physical syntax already latent in an ordinary trading-card rectangle.

Working card state:

```text
C = (K, I, A, H)
```

Where:

```text
K = CHARACTER  -- what particular carrier is here
I = INTERFACES -- what kinds of things it can fit with
A = AUTHORITY  -- what it is currently licensed to attempt
H = HISTORY    -- GREECEIPTS / formation road
```

Proposed physical geometry:

```text
+--------------------------------+
| CHARACTER             AUTHORITY|
|                                |
|                                |
|          CURRENT ROLE          |
|          / EXPRESSION          |
|                                |
|                                |
| INTERFACES            GREECEIPT|
+--------------------------------+
```

The center is not fixed identity.

```text
ROLE != IDENTITY
```

The border can act as constitution / boundary.
The back can carry decoder ancestry or shared grammar cues.
The corners remain persistent coordinates while the center can change through play.

This is design material, not yet a manufacturing specification.

# 8. DECK = DECODER

The next major phase shift was recognizing that a deck should not merely be a category of cards.

> **DECK = DECODER**

Examples:

```text
CHARACTER DECK -> who can act?
RELATION DECK  -> what can connect?
PLACE DECK     -> where can relations persist?
ECONOMY DECK   -> what can be exchanged?
CONFLICT DECK  -> what currently cannot coexist?
MEMORY DECK    -> what does this world remember?
LAW DECK       -> what moves are constituted here?
MYTH DECK      -> what meaning can propagate?
CRAFT DECK     -> what can be composed?
```

A plugin deck is higher-order.

It modifies another decoder rather than merely adding more cards.

```text
D_a --PLUGIN--> D_a'
```

Example from conversation:

```text
SEAFARING PLUGIN

```

The exact vocabulary is provisional.
The important law is not.

> **NEW ORDER = NEW KINDS OF THINGS THAT CAN FIT TOGETHER.**

# 9. OPEN COMPOSITION

The Minecraft pressure changed the question from recipes to interfaces.

A card does not need to say:

```text
WOOD + FIRE = CAMPFIRE
```

It may instead expose affordances:

```text
WOOD
CAN BE: carrier / fuel / structure / boundary / tool-material
ACCEPTS: cut / join / burn / shape / mark

FIRE
REQUIRES: fuel
CAN: transform / consume / signal / warm / destroy
```

Then:

```text
WOOD + FIRE
```

may lawfully become different things under different relations and frames.

Campfire.
Kiln.
Signal.
Arson.
Cooking.
A precursor to another machine.

Generated law:

> **COMPATIBILITY CONSTRAINS. PLAY DETERMINES EXPRESSION.**

A second sharpening followed:

> **IF IT APPEARS TO FIT, YOU MAY ATTEMPT THE COMPOSITION. REALITY SUPPLIES THE DELTA.**

The game must allow failure, hidden constraints, delayed consequences, and misread fits.

Otherwise it is not an aperture into open composition. It is only a recipe book with extra steps.

# 10. LAWFUL FREEDOM

The KOTOR pressure established that players should be able to do almost anything their current world can lawfully compose.

```text
YOU MAY DO ALMOST ANYTHING
IF YOU CAN LAWFULLY CONSTITUTE THE MOVE.
```

Lawful does not mean nice.
It does not mean morally approved by the table.
It does not mean optimal.

It means the move respects the currently required relation, authority, cost, continuity, constraint, and receipt.

A player may betray.
Build.
Steal.
Repair.
Found.
Destroy.
Trade.
Leave.
Return.
Attempt absurdity.

The game does not have to force virtue.
It has to preserve consequence.

# 12. PRUNE

PRUNE appeared because cooperation should not be imposed as a moral lecture.

The world should eventually become complex enough that isolated optimization cannot unlock the next order.

```text
COOPERATION IS NOT REQUIRED BY COMMAND.
IT BECOMES REQUIRED BY COMPLEXITY.
```

Conflict can arise between lawful local states.

The question is not simply:

> who wins?

It becomes:

> **WHAT CAN WE PRUNE WITHOUT DESTROYING WHAT EACH SIDE LAWFULLY BECAME?**

Working definition:

```text
PRUNE
  = remove unnecessary conflict
  + preserve earned distinction
  + reconstitute relation
```

Therefore:

```text
PRUNE != FLATTEN
PRUNE != SUPPRESS
PRUNE != FORCE AGREEMENT
```

Working harmony definition:

> **HARMONY = DIFFERENCE THAT CAN CONTINUE TO PLAY TOGETHER.**

Successful PRUNE should not merely award points.

It should expand expressive power.

```text
HARMONY -> NEW POSSIBILITY SPACE
```

The next mechanics become possible because the system can now carry more relation.

# 13. BAND: THE HIGHER-ARITY GATE

The existing Green Grammar / Dogram BAND work became mechanically relevant.

Some relations exist only when enough distinct participants are present.

```text
n_min > 1
```

Therefore the most powerful unlocks should not always belong to one player.

A sword may belong to one player.
A language, constitution, federation, trade network, ecology, school, peace treaty, or shared myth may require a higher-order relation.

Working game law:

> **THE GROUP CAN UNLOCK MECHANICS NO PLAYER COULD HAVE UNLOCKED ALONE.**

This is not mandatory collectivism.
It is an arity claim about certain game objects.

If the relation is genuinely higher-order, no individual should be able to counterfeit it alone.

# 15. CICADA: APERTURES, NOT ANSWERS

Generated import:

> **DON'T HIDE AN ANSWER IN THE CARD. HIDE AN APERTURE IN THE GRAMMAR.**

The card need not contain the whole future stage.
It needs only enough structure to lawfully expose the next operation once a player has learned how to read it.

Potential progression:

```text
CHARACTER
 -> DECODER
 -> NEXT CHARACTER
 -> NEW DECODER
 -> NEW MEDIUM
 -> NEW RELATION
```

The game should go beyond prewritten puzzle answers by allowing the players' own prior GREECEIPTS to become later decoder input.

```text
DESIGNER GRAMMAR
 -> PLAYER EVENT
 -> GREECEIPT
 -> LATER DECODER

```

HJJ boundary:

```text
NEW READING MAY CHANGE FUTURE ROLE.
NEW READING MAY NOT CHANGE WHAT HAPPENED THEN.
```

A communal research layer may eventually preserve successful and failed decoder attempts.

That would make the community's history of learning how to see into part of the game without requiring one master walkthrough.

# 16. PLAYING CARDS <-> TAROT: THE COMPRESSION DELTA

The conversation then noticed the aperture between a standard playing-card deck and a standard 78-card Tarot structure.

Conversation mathal:

```text
Tarot: 78 = 22 major + 56 minor
Minor: 4 x 14
Playing deck: 52 = 4 x 13
78 - 52 = 26
```

The conversation also noticed that the direct structural count difference can be described as:

```text
22 major cards
+ 4 extra court positions
= 26 cards
```

This is preserved as a **mathal / design specimen**, not a historical claim that Tarot was intentionally compressed into modern playing cards by removing exactly those semantic layers.

The important design reading was:

```text
PLAYING CARD
= high combinatoriality
+ low inscribed semantics

TAROT-LIKE SURFACE
= card grammar
+ more explicit semantic differentiation
```

Generated question:

> **WHAT HAD TO MOVE OUTSIDE THE CARD FOR THE SMALLER GRAMMAR TO REMAIN PLAYABLE?**

Answer candidate:

> meaning can move into the decoder.

```text
COMPRESSION DOES NOT NECESSARILY DESTROY MEANING.
IT CAN MOVE MEANING INTO THE DECODER.
```

This points REALITY.2 toward a sparse base deck and richer later decompressions.


> **ONE SET OF CHARACTERS CAN SUPPORT MULTIPLE LAWFUL COMPRESSIONS.**

```text
 -> FRUIT
```

depending on frame, relation, decoder, and receipts.

The game must preserve which road actually constituted the new character.

```text
 -> food-on-table?
```

Players may pursue incompatible objectives.
Do not force premature harmony.

# 24. HOSTILE CONTROLS

The design fails if:

```text
A recipe list replaces open composition.
A designer-only ontology decides every future category.
Printed rarity becomes the only meaningful particularity.
GREECEIPTS become XP stickers with no formation role.
A later decoder rewrites what happened earlier.
```

Especially:

> **DON'T QUOTIENT AWAY A DISTINCTION BEFORE PROVING IT IS SAFE TO FORGET.**
