
```math

```

Therefore the center adds no independent scalar information if it is *defined* as the whole. But redundancy can have a job: it becomes a checksum and a witnessed carrier for an already derivable quantity.

The center also simplifies reconstruction:

```math

Y = C - q
B = C - p
```

So:

```text

```



for this declared encoding: three degrees of freedom, four transmitted coordinates, minimum Hamming distance two.

A single coordinate corruption is detectable, and a single erased coordinate can be recovered when the other three are known.

## 6. Frequency decoder: translate every primitive by +4 Hz

Treat the three colors as arbitrary frequency carriers:

```math
R = f_R
Y = f_Y
B = f_B
```

and define the decoder:

```math
D4(f) = f + 4 Hz
```

A uniform translation preserves every pairwise difference:

```math
(f_i + 4) - (f_j + 4) = f_i - f_j
```

so differential / beat coordinates remain invariant.

Pair sums shift by eight:

```math
(f_i + 4) + (f_j + 4) = f_i + f_j + 8
```

and a three-member sum shifts by twelve:

```math
C' = C + 12
```

Thus, for additive relations constructed after the primitive transform:

```math
Delta(sum of n transformed members) = 4n
```

The shift records relation arity in this simple model:

```text
one member  -> +4
pair        -> +8
triple      -> +12
```

while difference coordinates remain fixed.

### Contrast control

A literal `+4 Hz` translation is not the same operator as changing a global tuning reference from A440 to A444. The latter is a scale by `444/440 = 111/110`, which preserves ratios rather than absolute differences.

```text
translation f -> f+4       preserves differences
scaling     f -> 111f/110  preserves ratios
```

Do not collapse the two decoders merely because both can be described colloquially as "four hertz up" at one reference point.
