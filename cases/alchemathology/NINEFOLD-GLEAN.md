# Ninefold Glean

Nine compression nodes for replaying the thread without carrying every conversational branch.

## 1 — VESSEL
**Compression:** boundaries determine which invariants and circulations are visible.

```text
change boundary
-> change represented transformation space
-> change what can conserve / circulate / disappear
```

Keeper: **the vessel partially defines sameness.**

## 2 — RECEIPT
**Compression:** endpoint state is a quotient of formation.

```text
same endpoint
!= same history
```

Keeper:

\[

\]

for a receipt that separates every hidden linear history direction.

## 3 — FOUR
**Compression:** four independent contributors generate:

\[

## 4 — FIVE
**Compression:** boundary closure and interior filling are different operations.

```text

```

Keeper: **bounded absence can become presence, and the previous hole class ceases to exist.**

## 5 — GATE
**Compression:** `FROM`, `THROUGH`, and `OUT-OF` require trajectory orientation, not only endpoint state.

Keeper:

```text

!= never entered
!= entered and exited
```

## 6 — EIGHTY-ONE
**Compression:** one ternary 4D world supports multiple lawful countings.

```text

81 = 1 + 40*2
subspaces = 1,40,130,40,1
40 = 13 + 27 relative to a gate
```

Keeper: **the decoder changes what structure becomes countable, not the underlying world.**

## 7 — NINE
**Compression:** `F_9` is the hidden intermediate field inside `F_81`.

```text
F_81 ~= F_9^2
Fix(x -> x^9) = F_9
81 = 10(9) - 9
9 = 4|1|4
```

Keeper: **a hidden intermediate layer can explain an apparent forward/back collapse.**

## 8 — TENET / PHI
**Compression:** inversion preserves a fixed floor.

```text
phi^n <-> phi^-n around 1
x <-> -x in F_3^4 around 0
81 = 40|1|40
```

Keeper: an inverse component can become tiny or quotient-invisible without becoming dispensable to exact formation.

## 9 — PEACH
**Compression:** a coherent object casts a larger lawful possibility-shadow.

```text

```

Keeper:

Required control:
