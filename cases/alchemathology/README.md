

## Hard red lines

- Symbol resemblance does not establish historical ancestry.
- Gematria or glyph decomposition does not establish physical mechanism.
- A higher-dimensional parameter space is not evidence for literal physical fifth-dimensional agency.
- Ordinary chemistry does not change elemental identity; literal elemental transmutation requires nuclear processes.
- Same endpoint does not imply same history.
- Replay does not establish historical identity.
- A tiny residual is not dispensable merely because it is small.
- A projected model being causally incomplete does not establish a supernatural cause.
