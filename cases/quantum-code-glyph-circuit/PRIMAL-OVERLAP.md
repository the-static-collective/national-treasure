# PRIMAL OVERLAP — BEFORE LETTER, NUMBER, LANGUAGE, OR DOMAIN

Status: **FLAGSHIP METHOD CORRECTION / ACTIVE RESEARCH LAYER**

The glyph-circuit case originally began too high in the stack.

The primary target is **not the modern Hebrew letter-shape as such**.

The target is the smaller visual/topological event that can recur as:

- a letter;
- a numeral;
- a diagram;
- an anatomical branch;
- a circuit junction;
- a cosmological partition;
- a developmental event;
- a mathematical relation;
- a ritual mark;
- a natural-scene contour.

The question is therefore:

> **WHAT IS THE SMALLEST VISUAL RELATION THAT SURVIVES WHEN DOMAIN-SPECIFIC MEANING IS REMOVED?**

This is the **primal overlap** layer.

---

## 1. Do not compare glyphs first. Compare topology.

Two visible marks may belong to the same primitive family even when:

- they have different names;
- they come from unrelated scripts;
- they carry different sounds;
- they have no historical transmission relation;
- one is a letter and the other is a numeral or diagram.

Conversely, historically related characters may drift into different visible topology.

So the comparison stack is:

```text
PIXEL / INK
   ↓
TOPOLOGY
point / line / bend / fork / crossing / loop / opening
   ↓
ORIENTATION
up / down / left / right / inward / outward
   ↓
DOMAIN REALIZATION
letter / number / body / circuit / story / map
   ↓
LOCAL MEANING
```

The research object lives primarily in the second and third layers.

---

# 2. Minimal primitive alphabet

A first deliberately tiny inventory:

```text
•   POINT
│   AXIS
─   SPAN
L   BEND
T   TERMINATION / OCCLUSION
Y   FORK / MERGE
X   CROSSING
U   OPEN ENCLOSURE / CUP
O   CLOSED ENCLOSURE / LOOP
```

These are **not letters here**. They are topological verbs frozen into minimal marks.

A possible operational vocabulary:

| Primitive | Minimal operation |
| --- | --- |
| `•` | localize / seed / event |
| `│` | extend / align / divide |
| `─` | span / connect / bound |
| `L` | bend / turn |
| `T` | terminate / meet / occlude |
| `Y` | branch / merge |
| `X` | cross / intersect |
| `U` | receive / hold-with-opening / return |
| `O` | enclose / cycle / complete |

This is close to the topology research of Changizi, Zhang, Ye & Shimojo, who compared recurrent contour configurations across writing systems, Chinese writing, and nonlinguistic symbols. Their method explicitly treats L-, T-, X-, Y-like and other configurations as topological types rather than as particular letters. They report similar configuration distributions across visual sign systems and argue that cultural visual signs tend to reuse contour structures common in natural scenes.

Primary research:

- Mark A. Changizi, Qiong Zhang, Hao Ye & Shinsuke Shimojo, **“The Structures of Letters and Symbols throughout Human History Are Selected to Match Those Found in Objects in Natural Scenes,”** *The American Naturalist* 167.5 (2006), DOI `10.1086/502806`.
- Helena Miton & Olivier Morin, **“Graphic complexity in writing systems,”** *Cognition* 214 (2021), DOI `10.1016/j.cognition.2021.104771`.
- Yoolim Kim et al., **“The phonology of letter shapes: Feature economy and informativeness in 43 writing systems,”** *Journal of Memory and Language* 142 (2025), DOI `10.1016/j.jml.2025.104620`.

This gives the primal-overlap program an empirical control:

> **RECURRENCE OF A TOPOLOGY DOES NOT REQUIRE COMMON HISTORICAL DESCENT.**

Some overlap may arise because human vision and motor behavior repeatedly favor a small repertoire of useful marks.

# 4. Natural scene control

The topological recurrence of L/T/X/Y-like structures across visual signs has a non-mystical baseline: they also occur in ordinary visual environments.

Examples:

```text
L = two contours meeting at a corner
T = one contour terminating against / occluded by another
Y = three-way junction
X = crossing / transparency / adjacency configurations
```

This matters enormously.

If the same primitive appears in:

```text
TREE BRANCH
BLOOD VESSEL
RIVER DELTA
LETTER Y
CIRCUIT SPLIT
FAMILY TREE
CHOICE DIAGRAM
```

we must first consider:

> **THE SAME TOPOLOGICAL PROBLEM PRODUCES THE SAME MINIMAL FORM.**

Only after controlling for that should historical or metaphysical linkage be considered.

That does not make the convergence uninteresting.

It makes the convergence **deeper than language**.

# 5. Garbhāvakrānti × Genesis — correct comparison level

The prior remembered term was the **Garbhāvakrāntisūtra / Nandagarbhāvakrānti** tradition, a Buddhist `entry into the womb` text with a detailed week-by-week gestational sequence conventionally described as thirty-eight weeks. Robert Kritzer's work compares this week-by-week account with Indian medical embryology. A Tocharian witness has a 37-week formulation, so `38` must not be promoted into a sacred invariant without textual control.

Useful sources:

- Robert Kritzer, **“Life in the Womb: Conception and Gestation in Buddhist Scripture and Classical Indian Medical Literature,”** in *Imagining the Fetus* (Oxford, 2008), DOI `10.1093/acprof:oso/9780195380040.003.0005`.
- Robert Kritzer, *Garbhāvakrāntisūtra: The Sūtra on Entry into the Womb* (International Institute for Buddhist Studies, 2014).
- 84000, *The Teaching to the Venerable Nanda on Dwelling in the Womb* (Toh 57).
- A. Leroi et al., **“Aristotle, Buddhist scripture and embryology in ancient Mexico,”** *Development* (2021), which remarks on the unusual developmental detail in the Buddhist account.

The Buddhist text and Genesis are **not** currently linked by evidence of transmission.

The proposed overlay therefore belongs at the level of **compressed generative operations**.

That can be tested across many traditions and domains.

# 7. The high-value experiment: compression before comparison

This is the anti-overfit procedure.

For each source/domain:

1. Give the source to an analyst who does not see the target comparison.
2. Ask them to compress each transition into a fixed primitive vocabulary.
3. Preserve sequence order.
4. Only then compare primitive strings.

Example output:

```text
GENESIS:
DISTINGUISH → SEPARATE → GATHER → ORIENT → MULTIPLY → EMBODY → COMPLETE

GARBHĀVAKRĀNTI:
CONDENSE → DIFFERENTIATE → BRANCH → ORGANIZE → GROW → COMPLETE → EXIT

EMBRYOLOGY MODERN:
FERTILIZE → CLEAVE → AXIS → DIFFERENTIATE → MORPHOGENESIS → GROW → BIRTH

TREE:
SEED → AXIS → BRANCH → BRANCH → ENCLOSE/GROW → FRUIT → RELEASE
```

Then map words to the fixed topology alphabet.

If the overlap exists only after custom translation for each target, it fails.

If independent compression repeatedly lands on the same small operation grammar, that becomes a real result.

# 8. Letters and numbers

The primal-overlap program must explicitly include numerals because similar geometry does **not** imply shared linguistic ancestry.

Useful control examples:

```text
O / 0
I / 1 / |
S / 5  (font-dependent visual resemblance)
B / 8  (double-enclosure family)
```

The correct question is not:

> `O and 0 secretly mean the same thing.`

It is:

> **what operation makes a closed loop useful enough to recur independently as letter, numeral, diagram, boundary, cycle, zero, eye, ring, orbit, cell, and enclosure?**

This distinction is the heart of the program.

# 9. Three kinds of overlap

Every apparent recurrence must be classified:

```text
GENEALOGICAL OVERLAP
same sign-family transmitted historically

ECOLOGICAL OVERLAP
independent signs converge because human vision / gesture / environment favor the topology

STRUCTURAL OVERLAP
different domains instantiate the same abstract relation
```

A fourth category remains open:

```text
ONTOLOGICAL OVERLAP
same topology recurs because reality itself is generated by a restricted relational grammar
```

That is the flagship speculation.

It cannot be inferred merely from the first three.

But the first three give us a rigorous path toward testing it.
