# Bounty — LET THE FLOW WRITE THE BRAID

**Priority:** high  
**Status:** open  
**Question:** does a physically specified S/serpentine flow generate a nontrivial three-strand braid without choosing the braid word by hand?

---

## Why this is the next discriminator

The current stack contains two different statements:

1. a declared braid such as `sigma_1 sigma_2^-1` has exact golden-ratio stretch properties;
2. curved/alternating channels can generate secondary circulation and chaotic stretching under some regimes.

The missing edge is physical formation:

```text
specified channel + fluid parameters + initial markers
        -> measured trajectories
        -> extracted braid word
        -> entropy / stretch receipt
```

Without that edge, placing a golden or silver braid inside an S-channel is chosen symbolism.

With that edge, the flow itself writes the topological history.

---

## Bounty A — cheapest simulation

Use a published or validated velocity field for a curved/serpentine channel.

Pre-register:

- geometry;
- Reynolds / Dean regime;
- three initial tracer positions;
- observation direction and crossing convention;
- integration horizon;
- braid-extraction method;
- null condition (straight channel or low-Dean regime);
- success/failure thresholds.

Then:

```text
integrate tracer paths
-> project consistently
-> detect strand crossings
-> emit braid word
-> reduce/conjugacy-check where appropriate
-> calculate topological entropy / stretch bound
```

Do **not** tune initial points after seeing a favored word.

### Strong result

A nontrivial braid recurs across a preregistered family of initial conditions or repeated cells and materially predicts stretching better than the null.

### Strong negative result

The flow generates trivial/low-entropy braid histories or results vary arbitrarily with projection/initialization.

Both outcomes are useful.

## Bounty B — hostile sibling sweep

Test at least three constitutions:

```text
LOW: secondary flow weak / near reversible
MID: organized two-vortex secondary flow
HIGH: four-vortex / strongly mixing regime
```

Ask whether the braid class changes at the same regime transitions identified by ordinary fluid observables.

This pressures:

```text
NUMBER BELONGS TO TRANSFORMATION CLASS
```

because the candidate stretch factor should change when the physical transform class changes.

## Bounty C — mutation-residual test

For each S-cell define an expected reversal map `J` **before** evaluating the output.

Record actual cross-section state `T(x)` and calculate

```math
\mu(x)=JT(x)-x.
```

Compare:

- norm of `mu`;
- symmetric / antisymmetric components;
- extracted braid history;
- fluid regime indicators.

Question:

> Does the residual become systematically nonzero when the physical system leaves the approximately reversible regime?

This is the cleanest test of the `MUTATION = UNTRANSPORT(OUTPUT) - INPUT` proposal.


## Promotion gates

Promote the bounty only if all of these remain true:

- braid word is extracted from trajectories, not selected first;
- projection convention is fixed and receipt-bearing;
- straight/low-regime nulls are included;
- initial-condition sensitivity is measured;
- `phi` or `delta` is reported only if generated by the extracted transform;
- same endpoint geometry is not substituted for braid history;
- physical stretching data are compared with topological prediction;
- null/failed results remain durable.
