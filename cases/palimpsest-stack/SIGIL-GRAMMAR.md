# Sigil Grammar — Geometry Becomes Speech

Status: **[DESIGN] primitive-incubator language hypothesis**

Date: 2026-08-22

This document records a newly visible consequence of the existing `P0..PF` shape language and morphology operators.

It does not claim the symbols are ancient, universal, sacred, cryptographic, or authoritative.

> **Geometry can carry grammar without pretending geometry is universal meaning.**

## Discovery

The sixteen primitives are no longer merely a visual catalogue once they are combined with declared transformation operators and ordered composition.

A useful working analogy is:

```text
primitive        ≈ letter / root / lexical atom
operator         ≈ verb / inflection
ordered relation ≈ syntax
host context     ≈ pragmatics
receipt lineage  ≈ attributable semantics
history          ≈ tense / aspect
refusal / cut    ≈ negation / unavailable continuation
```

The analogy earns continued use only where it improves actual compositional reasoning.

## Morphology

The existing shape operators become grammatical actions:

```text
TRANSLATE  ROTATE  REFLECT  SCALE
REPEAT     OVERLAP LIGATE   CUT
OPEN       CLOSE   NEST     BRANCH
MERGE      PROJECT
```

An operator changes how a primitive participates while declaring what it preserves and what it loses.

That is language-like because a form can change while its attributable root remains inspectable.

## Syntax

Order, scope, and named inputs matter.

```text
P8 -> CUT -> PE
```

is not presumed equivalent to:

```text
PE -> CUT -> P8
```

Likewise:

```text
NEST(P8, PC)
```

is structurally distinct from:

```text
OVERLAP(P8, PC)
```

A useful sigil expression therefore needs recoverable:

- roots;
- operator sequence;
- operator scope;
- named inputs where composition occurs;
- preserved and lost features;
- lineage to prior expressions.

A bag of attractive icons is not grammar.

## Semantics remain typed

The proposed semantic assignments of `P0..PF` may provide stable roots, but host systems retain local authority over consequence.

```text
shape meaning
  != execution authority
  != identity proof
  != historical ancestry
```

A visual expression may communicate `refusal`, `branch`, or `witness` while remaining incapable of granting capability or deciding identity.

This preserves the existing Cicada rule:

```text
MYSTERY SURFACE
  != VERIFICATION SURFACE
  != AUTHORITY SURFACE
```

## Witness-locked and free-sigil channels

The same geometric alphabet may participate in two materially different channels.

### Witness-locked

```text
canonical digest
  -> frozen witness-sigil/v0.1 projection
  -> optional downstream derived topology
```

The frozen projection remains recoverable and immutable.

A creative descendant must never impersonate the canonical Witness Sigil that seeded it.

### Free-sigil

```text
P0..PF + morphology
  -> creative expression
```

No receipt identity or digest meaning is implied.

The two channels may share geometry while remaining mechanically and visibly distinguishable.

## Time can become grammar

Static shape is not the only possible carrier.

The Haunted Toaster already provides a useful temporal vocabulary:

```text
hold
  -> apparition
  -> resonant overlap
  -> dissolve | scar | succession
```

This suggests a future temporal layer analogous to grammatical aspect:

- **hold** — persistent present;
- **apparition** — temporary appearance;
- **scar** — prior event with surviving residue;
- **succession** — one expression becomes the accepted descendant;
- **recursive return** — recurrence with declared difference.

The importance of the analogy is operational: the expression can preserve **what happened through time**, not only final geometry.

## Productive-language test

A combinatorial symbol system becomes more language-like if it can support **productive novelty**.

Three tests matter:

1. **Recognition** — can a recurring expression be recognized across different visual skins?
2. **Composition** — do ordered roots and operators produce distinguishable reusable consequences?
3. **Productive novelty** — can a never-before-seen expression still be interpretable because its parts and grammar are familiar?

The third is the strongest evidence.

A language is not only a catalogue of known sentences.
It allows new sentences to be understood.

Let use precede canon.

Dead, ambiguous, or misleading expressions are evidence too.
