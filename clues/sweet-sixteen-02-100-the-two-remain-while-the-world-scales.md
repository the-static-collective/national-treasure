## 6. The boring math that makes 02 → 100 useful

For positional base `b >= 3`:

```math
02_b = 2
100_b = b^2
```

Therefore:

| decoder | `02` | `100` |
| --- | ---: | ---: |
| base 3 | 2 | 9 |
| base 4 | 2 | 16 |
| base 5 | 2 | 25 |
| base 10 | 2 | 100 |

This is the first strong invariant/variant split:

```text
02
-> stable pair-value under tested radices

100
-> world-scale value determined by the receiving radix
```

Candidate compression:

> **THE TWO CAN REMAIN TWO WHILE THE WHOLE CHANGES SCALE.**

Do not promote this into a universal metaphysical law.

It is an exact positional-number specimen that happens to be useful for the active relational question.
